BASERA — HTML/CSS/JavaScript Prototype

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. No server or installation is required.

PROTOTYPE FEATURES
- Responsive landing page
- Search by college/area/property
- Type, rent, room, rating and amenity filters
- Property cards and details
- Favourites using localStorage
- Compare up to 4 properties using localStorage
- Property enquiry demo
- Owner property submission demo
- Sample accommodation dataset
- Responsive mobile layout
